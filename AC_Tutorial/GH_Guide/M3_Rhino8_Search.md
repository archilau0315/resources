# Rhino 8 组件搜索与自动补全 / Component Search and Auto‑Complete

## 1. 顶部搜索框 / Top Search Bar
- 在 Grasshopper 画布右上角放置 **搜索输入框**（宽度约 250 px）。  
- 输入关键字时实时进行 **模糊匹配**（不区分大小写）。  

## 2. 自动补全下拉列表 / Auto‑Complete Dropdown
- 输入前三个字符即可弹出匹配组件列表。  
- 列表项包括 **组件名称**、**参数名称**、**帮助链接**。  
- 点击列表项可直接跳转到该组件的帮助页面或在画布中定位该组件。

## 3. 匹配规则 / Matching Rules
- **组件名称**：包含输入字符的任意位置均匹配。  
- **参数名称**：参数标签文字也参与匹配。  
- **描述文本**：组件帮助描述中的关键词会被纳入搜索。  

## 4. 交互行为 / Interaction Behaviors
| 操作 | 结果 |
|------|------|
| 输入文字 | 动态过滤组件列表，仅显示匹配项 |
| 单击匹配项 | ① 在画布中定位该组件（高亮）<br>② 打开其帮助页面（新标签页） |
| 按 **Esc** 键 | 关闭下拉列表，保持当前搜索状态 |
| **Enter** 键 | 在当前画布中创建一个新的相同名称组件（若不存在） |

## 5. 实现要点 / Implementation Tips
- 使用 **C# Script** 或 **GhPython** 读取画布中所有组件的名称与参数，构建搜索索引。  
- 通过 **GH_ComponentUtil**（Hermes 插件）实现 UI 交互，确保与 Rhino 8 原生 UI 风格一致。  
- 为每个组件预存 **唯一 ID**（Guid），防止名称冲突导致误匹配。
