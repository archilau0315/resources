# Rhino 8 环境准备 / Environment Preparation

## 1. 安装 Rhino 8
- 下载官方安装包：https://www.rhino3d.com/download/
- 运行安装程序，选择默认选项，完成安装后重启电脑。

## 2. 启动 Grasshopper
- 在 Rhino 中打开 **Tools > Manage Plugins**，确保 **Grasshopper** 已启用。
- 通过 **Tools > Grasshopper** 或在命令行输入 `Grasshopper` 启动 Grasshopper 窗口。

## 3. 界面概览
- **Canvas**：空白画布，拖拽组件并连线。
- **Parameters**：双击组件可调节参数。
- **Preview**：右侧面板显示组件预览，可右键关闭预览以提高性能。

## 4. 基本设置
- 分辨率：`Edit > Preferences > Performance`，建议将 **Display** 设置为 **OpenGL** 以获得更流畅的渲染。
- 保存默认工作文件：`File > New` 创建空画布，后续保存为 `.gh` 文件。

## 5. 小结 / Summary
- 完成以上步骤后，您即可在 Rhino 8 中使用 Grasshopper 进行参数化建模。
