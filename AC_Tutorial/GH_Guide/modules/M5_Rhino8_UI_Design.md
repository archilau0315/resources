# Rhino 8 UI/UX 设计与美化 / UI/UX Design and Beautification

## 1. 设计原则 / Design Principles
- **简洁优先**：界面元素少而有效，避免信息过载。  
- **一致性**：所有组件使用相同的视觉语言（颜色、字体、间距）。  
- **可读性**：文字大小适中，对比度高，便于长时间观察。  

## 2. 颜色方案 / Color Scheme
- **背景**：深灰 #2B2B2B（减轻眼睛疲劳）。  
- **主要文字**：纯白 #FFFFFF。  
- **强调色**：Rhino 官方蓝 #0078D7，用于按钮、高亮。  
- **次要颜色**：浅灰 #A0A0A0，用于次要文字或占位符。  

## 3. 字体与间距 / Typography & Spacing
- **字体**：系统默认等宽字体（Consolas），确保代码和参数对齐。  
- **行间距**：8 px，段落间距 16 px。  
- **组件间距**：水平 8 px，垂直 12 px，保持视觉呼吸。  

## 4. 布局网格 / Layout Grid
- **列网格**：12 列，列宽 48 px，列间距 16 px。  
- **行间距**：垂直 24 px，帮助分层组件。  
- **安全区**：画布左/右边缘保持 48 px，防止重要信息被遮挡。  

## 5. 交互反馈 / Interaction Feedback
- **悬停效果**：组件悬停时轻微放大 5%，颜色变亮 10%。  
- **点击动画**：轻微缩放 0.95，随后恢复，提供视觉确认。  
- **错误提示**：红色边框 + 文字提示，保持信息可见。  

## 6. 响应式适配 / Responsive Adaptation
- **宽屏模式**：左侧导航栏（组件库）固定显示，右侧为主画布。  
- **窄屏模式**：导航栏折叠为图标栏，画布占满全屏，搜索框始终可见。  

## 6. 主题切换 / Theme Switching (可选)
- **深色模式**：当前默认，适合长时间工作。  
- **浅色模式**：仅用于演示或打印输出，背景改为 #F5F5F5，文字改为 #222222。  

## 7. 样式指南 / Style Guide Summary
- **颜色**：#2B2B2B（背景），#FFFFFF（文字），#0078D7（强调），#A0A0A0（次要）。  
- **字体**：Consolas，13 pt 为正文，16 pt 为标题。  
- **间距**：水平 8 px，垂直 12 px，行间距 8 px。  
- **组件形状**：圆角矩形 4 px，边框 1 px，颜色 #444444。
