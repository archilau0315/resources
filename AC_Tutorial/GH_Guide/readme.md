# GH 指南 | GH Guide — Rhino 8 / Grasshopper 用户手册与组件速查

## 项目用途 | Purpose

GH 指南（GH Guide）是一个面向 Rhino 8 / Grasshopper 用户的统一学习门户。它整合了从环境准备、基础操作、组件搜索、参数详解、UI/UX 设计，到完整实战项目、组件开发、测试验证、打包分发与 CI/CD 部署的全链路教程，并内置 817 个 Rhino 8 原生组件目录，支持智能搜索与自动补全。界面中英双语，图文并茂，可直接离线运行。

GH Guide is a unified learning portal for Rhino 8 / Grasshopper users. It integrates a full-stack curriculum from environment setup, basic operations, component search, parameter details, UI/UX design, to hands-on projects, component development, testing, packaging and CI/CD deployment, plus a built-in catalog of 817 native Rhino 8 components with smart search and autocomplete. Bilingual CN/EN, illustrated, runs fully offline.

## 使用说明 | Usage

1. 直接用浏览器打开 `index.html` 即可运行，无需安装、无构建步骤、无依赖。
2. 首页包含 **课程地图**（按学习路径浏览 20 个模块）和 **组件目录**（817 个原生组件）。
3. 使用顶部搜索框可搜索课程或组件，支持中英混合输入与自动补全。
4. 点击任意模块卡片进入详情页，可跳转到对应的 Markdown 完整文档。
5. 右上角按钮可一键切换中文 / 英文界面。

1. Open `index.html` directly in a browser, no installation, build step, or dependencies required.
2. Home page includes **Course Map** (20 modules in learning path order) and **Component Catalog** (817 native components).
3. Use the top search bar to search courses or components; Chinese/English mixed input with autocomplete is supported.
4. Click any module card to open its detail page and jump to the full Markdown documentation.
5. Use the top-right button to switch between Chinese and English UI.

## 核心特性 | Core Features

- 🎯 单源数据：所有课程数据存储在 `assets/data/curriculum.json`，中英字段同文件保存。
- 🔍 智能搜索：支持前缀、子串与字符顺序智能打分，按相关度排序。
- 🌐 中英双语：全站中英双语，右上角一键切换，无需刷新。
- 📱 响应式：适配桌面与移动端，暗色专业主题。
- 🧩 组件目录：817 个 Rhino 8 原生组件，带输入/输出参数详解与官方文档链接。
- 📦 轻量离线：纯前端 HTML/CSS/JS，无构建步骤，无依赖，可直接离线运行。

- 🎯 Single-source data: all curriculum data in `assets/data/curriculum.json`, both languages in one record.
- 🔍 Smart search: prefix, substring, and smart character-order scoring, sorted by relevance.
- 🌐 Bilingual CN/EN: full-site bilingual, one-click switch at top-right, no reload.
- 📱 Responsive: desktop and mobile adaptive, dark professional theme.
- 🧩 Component catalog: 817 Rhino 8 native components with input/output parameter details and official doc links.
- 📦 Lightweight & offline: pure HTML/CSS/JS, no build step, no dependencies, runs fully offline.
