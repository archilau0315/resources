# _work · 本站项目工作目录

## 用途

kbitai.com.cn 站点（含 AC_Tutorial 教程站、AUtrain 内训资料）的杂项工作文件集中存放处。
AI 助手会话产生的临时脚本、抓取中间产物、会话记忆与工作日志放这里，避免散落到站外目录。

**注意**：本目录不属于站点发布内容，不被任何页面引用；`_` 开头也是为了让它在资源列表里排在最前、一眼可见。

## 目录结构

```
_work/
├── readme.md          本说明
├── debug_log_1.md     本目录的变更记录
└── memory/            会话记忆与每日工作日志
    └── YYYY-MM-DD.md
```

后续可按需要增设子目录（如 `tmp/` 放一次性中间文件、`scripts/` 放本站通用小工具）。

## 使用说明

- 一次性中间产物（截图、打包、临时 json）用完即删，不要长期堆积。
- 需要长期保留的脚本，按用途归到对应项目目录（如教程站脚本放 `AC_Tutorial/ci_tools/tools/`），不要停在 `_work`。
- 与站点部署相关的文件不要放这里——`_work` 不参与部署脚本。

## 边界

| 内容 | 该放哪儿 |
|---|---|
| 教程站构建/注入脚本 | `AC_Tutorial/ci_tools/tools/` |
| 教程站页面与图片 | `AC_Tutorial/ci_tools/site/` |
| 内训部署与登录逻辑 | `AUtrain/tools/` |
| 资源页图标与缩略图 | `resources/` 根目录（被页面引用） |
| 会话记忆、临时产物 | 本目录 |
