## 📖 关于本仓库 · About This Repository

**中文** — 这是一个面向建筑性能模拟与 BIM 从业者的**学习资源集合**，把 Ladybug Tools、Grasshopper 2、Archicad CI Tools、Archicad GDL 四款工具的官方组件 / 命令 / 文档整理成**可搜索、带截图、中英双语**的在线速查站与系统教程，全部部署在 [kbitai.com.cn](https://www.kbitai.com.cn/)，国内可直接打开，无需翻墙。每个子项目都是独立的零依赖静态站点（或 VitePress 站点），可单独运行、单独部署。

**English** — A curated **learning resource library** for building‑performance simulation and BIM practitioners. It turns the official components, commands and documentation of **Ladybug Tools, Grasshopper 2, Archicad CI Tools and Archicad GDL** into **searchable, screenshot‑rich, bilingual (ZH/EN)** online references and tutorials. Everything is hosted on [kbitai.com.cn](https://www.kbitai.com.cn/) and opens directly in mainland China — no VPN needed. Each sub‑project is an independent zero‑dependency static site (or VitePress site) you can run and deploy on its own.

## 🖥️ 本地运行 · Run Locally

**中文** — Honeybee、GH2、CI Tools 三个项目是纯静态站，用 `fetch` 读取数据，**不能直接双击 `index.html`**（浏览器会拦截），需通过本地 HTTP 服务打开：

**English** — The Honeybee, GH2 and CI Tools projects are pure static sites that load data via `fetch`. **Do not double‑click `index.html`** (the browser will block it); serve it over a local HTTP server instead:

```bash
# 任选其一 / Pick one:
python -m http.server 8080          # Python 3
npx serve .                          # Node
```

然后打开对应入口 / then open:
- Honeybee → `http://localhost:8080/AC_Tutorial/honeybee/site/index.html`
- GH2 → `http://localhost:8080/AC_Tutorial/gh_guide/site/index.html`
- CI Tools → `http://localhost:8080/AC_Tutorial/ci_tools/site/index.html`

**GDL 教程** 是 VitePress 项目，需安装依赖后构建 / GDL is a VitePress project — install deps then build:
```bash
cd AC_Tutorial/GDL_Tutorial
npm install
GDL_BASE=/resources/GDL_Tutorial/ GDL_SITE_URL=https://www.kbitai.com.cn npm run build
```

各项目的详细说明见各自目录的 `readme.md`。 / See each project's `readme.md` for details.
